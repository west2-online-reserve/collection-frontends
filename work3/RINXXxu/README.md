>JavaScript 通过回调函数，让程序可以在未来的某个时刻执行代码，而不会卡住其他任务。这就是回调函数最根本的作用。  

>在编程世界里，含义是相反的：（相较于生活中）  
同步（Synchronous）：指代码按顺序执行，一件事彻底做完，才做下一件。这期间，程序是“阻塞”的，没法响应别的事情。  
异步（Asynchronous）：指代码可以发起一个任务后，不等它完成，先继续往下执行，等这个任务有了结果再回过头来处理。程序是非阻塞的，可以同时应对多个任务。

>你可以把 await 理解为 return 的变种：  
普通 return：函数彻底结束，返回一个值。  
await：函数暂时返回（交出控制权），同时注册一个“恢复标签”。等异步操作完成了，系统再通过这个标签让函数从断点处继续执行。
