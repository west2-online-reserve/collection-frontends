学习数据类型转换。手动：Number(),String(),Boolean().Number()比parseInt()更为严格，都会自动过滤前导/后置空格。自动转换会根据预期值转换，因而尽量使用手动转换减少问题。  
学习console相关。console.log()用于显示台上的输出，整体用法和printf差不多，但可以自定义，更加灵活。  
学习Date对象。普通函数情况下，Date返回当前时间的字符串，构造函数情况下，Date接受可解析的参数并返回对应时间。
