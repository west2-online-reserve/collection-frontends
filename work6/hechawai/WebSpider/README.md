# Web Spider - 福州大学通知爬虫

## 项目简介

爬取福州大学通知文件系统上 2026 年 1 月 1 日至今的所有通知，包括：

- 发表日期
- 发布部门
- 通知标题
- 访问链接
- 通知正文（Bonus）
- 访问人数（Bonus）

## 环境要求

- Node.js >= 14
- 校园网环境（或 VPN）

## 安装依赖

```
npm install
```

## 运行爬虫

```
node crawler.js
```

## 输出结果

爬取结果保存在 notices.json（没有自动创建）中，每条记录格式如下：

```
{
  "title": "通知标题",
  "link": "访问链接",
  "date": "2026-06-11",
  "department": "【教务处】",
  "content": "通知正文内容...",
  "views": 1234
}
```

## 数据字段说明

| 字段         | 类型     | 说明                   |
| ------------ | -------- | ---------------------- |
| `title`      | `string` | 通知标题               |
| `link`       | `string` | 详情页链接             |
| `date`       | `string` | 发布日期（YYYY-MM-DD） |
| `department` | `string` | 发布部门               |
| `content`    | `string` | 通知正文（Bonus）      |
| `views`      | `number` | 访问人数（Bonus）      |

## 功能特点

- 自动翻页爬取通知
- 按日期筛选
- 并发请求控制（p-queue，默认并发数 3）
- 爬取详情页正文和访问人数
- 自动生成唯一文件名
- 数据保存到 JSON 文件

## 注意事项

- 需要连接校园网或 VPN 才能访问
- 请勿设置过高的并发数，避免对服务器造成压力
